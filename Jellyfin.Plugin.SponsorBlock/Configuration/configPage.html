SponsorBlock Settings

Libraries

Pick the libraries this plugin should fetch SponsorBlock data for. With nothing selected the plugin is inactive.

Refresh Schedule

The "SponsorBlock daily refresh" task triggers once per day at this hour.

YouTube ID

Metadata mode reads Jellyfin's Youtube provider ID, normally imported from <uniqueid type="youtube"> in an NFO file. The standalone <youtubeid> element is not supported.
Must contain one capture group for the YouTube video ID. Default: \[([a-zA-Z0-9_-]{11})\] — matches [videoID] in filenames.

Categories to Skip

Paid promotional content
Creator's own products, merch, or services
"Like, subscribe, comment" reminders
Repeating intro animation or sequence
Endcards and credits
Clips previewing upcoming content
Tangential content, jokes, or padding
Non-music sections in music-focused videos

Each user controls skip behavior per-device under Settings → Playback → Media Segments. Jellyfin stores these preferences in the browser's local storage, so they cannot be configured centrally.

Force scan

Scans every video in the selected libraries once. Use this after enabling the plugin for an existing archive. The daily refresh also discovers old selected-library items and keeps checking items until they either get SponsorBlock data or enter cooldown.

Reset

Wipes the SponsorBlock state and removes all media segments owned by this plugin for every item in the selected libraries above. Items are then treated as freshly added — the next playback re-fetches segments, as does a daily refresh once the item is older than the sanity-check window.
